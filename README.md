# Secure Voice Communication using Crypto-Coding Polar Codes

Raspberry Pi implementation of a secure voice communication system using:

- Polar Code (512,256)
- Dynamic Frozen Bits
- AES/SNOW-V Keystream
- Audio Crypto-Coding
- Raspberry Pi 4
